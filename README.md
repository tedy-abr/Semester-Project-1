## Community Science Museum

![museum](https://github.com/user-attachments/assets/3fbcac79-f920-4349-941d-425f63086c4d)

A responsive and engaging website for a fictional science museum, designed for children (ages 7–15) and their families. The project focuses on delivering educational value through a fun and accessible interface.

## Description

The Community Science Museum is a fictional, educational website aimed at encouraging children and families to explore science through an engaging digital experience. The site features multiple pages with clear navigation, responsive design, and accessible content, built using semantic HTML and clean CSS.


## Built with
- HTML
- CSS


## Feautres
- Fully responsive layout (mobile, tablet, desktop)
- Optimized images and fast loading times
- Semantic HTML with accessibility in mind (WCAG)
- Designed for young users with colorful and playful aesthetics
- Clear page structure
